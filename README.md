# Nepal Trails – Discover Nepal

A responsive travel landing page showcasing the natural beauty, destinations, culture, and adventures of Nepal.

## Features
- Responsive navigation bar
- Hero section with background image
- Popular destinations: Pokhara, Kathmandu, and Chitwan
- Experiences section featuring culture, trekking, and boating
- About Nepal section
- Plan Your Trip call-to-action
- Responsive layout for mobile, tablet, and desktop

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome

## Project Structure
```text
nepal-trails/
├── index.html
├── style.css
├── images/
└── README.md
```

## How to Run
1. Clone this repository:
   `git clone YOUR_GITHUB_REPOSITORY_URL`
2. Open the project folder.
3. Open `index.html` in your browser.
