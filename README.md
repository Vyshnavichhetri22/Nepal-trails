# Nepal Trails – Discover Nepal

A responsive travel landing page showcasing the natural beauty, destinations, culture, and adventures of Nepal.

## 🌐 Live Demo

[View Nepal Trails Website](https://vyshnavichhetri22.github.io/Nepal-trails/)

## 📂 GitHub Repository

[View Source Code](https://github.com/Vyshnavichhetri22/Nepal-trails)

## Features

- Responsive navigation bar
- Hero section with background image
- Popular destinations: Pokhara, Kathmandu, and Chitwan
- Experiences section featuring culture, trekking, and boating
- About Nepal section
- Plan Your Trip call-to-action
- Responsive layout for mobile, tablet, and desktop

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome

## How to Run Locally

1. Clone the repository:

   `git clone https://github.com/Vyshnavichhetri22/Nepal-trails.git`

2. Open the project folder.
3. Open `index.html` in your browser.
